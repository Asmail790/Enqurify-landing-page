# AI usage

Where AI was used while building this page.

- Researching other products like this one (Gemini, DeepSeek) and what makes a good landing page.
- Creating the initial semantic CSS tokens, based on the Atlassian Design System and the values from the Tailwind CSS colour generator at uicolors.app/generate/3ca379. The page colours and values were copy-pasted from there.
- Fixing alignment issues.
- Writing the JS animation, which will later be turned into an image.
- Applying the semantic tokens.
- Copying some parts of the existing website, such as the header and footer, the Enquirify Voice and Enquirify Forms sections, and the page text.
- Writing the dashboard.
- Scaffolding the initial web page.
- CSS assistance: converting inline CSS to Tailwind CSS using the semantic tokens I defined.
- Dirty SVG icon generation.
